[STEAM_TITLE:Mod Load Order (DFHack)]
[STEAM_DESCRIPTION:Requires DFHack. Adds a panel to the Create world / Mods screen that checks your active mod list and helps fix it. Fixes load order using each mod's "must be before / after" rules, removes conflicting mods in one batch (asks first), alerts you to missing required mods, scans the mods' raw files for hidden conflicts, suggests order changes for mods with no rules, switches to newer installed versions, and warns before you create a world with problems. Everything can be undone. You don't need to activate it in your mod list - subscribing is enough.]

[STEAM_TAG:interface]
[STEAM_CHANGELOG:v1.5 - Graphics overlaps retired for now. The Graphics overlaps section has been removed from the Hidden conflicts tab, along with its count on the Overview tab, the panel and the Mod info tab. Which mod's artwork should win is really a matter of taste, and acting on these could leave a world looking worse than before - newer vanilla art is often the better choice. Graphics order is now left to each mod's own load-order rules, which the tool still checks and fixes. The detection is still built in, so it can come back in a smarter form later.]
