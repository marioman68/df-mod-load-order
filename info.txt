[STEAM_TITLE:Mod Load Order (DFHack)]
[STEAM_DESCRIPTION:Requires DFHack. Adds a panel to the Create world / Mods screen that checks your active mod list and helps fix it. Fixes load order using each mod's "must be before / after" rules, removes conflicting mods in one batch (asks first), alerts you to missing required mods, scans the mods' raw files for hidden conflicts and graphics overlaps, suggests order changes for mods with no rules, switches to newer installed versions, and warns before you create a world with problems. Everything can be undone. You don't need to activate it in your mod list - subscribing is enough.]
