[STEAM_TITLE:Mod Load Order (DFHack)]
[STEAM_DESCRIPTION:Requires DFHack. Subscribe only - you do not need to activate this mod in your mod list (DFHack loads it automatically and it hides itself from the list).

Adds a compact status panel and a full tabbed window to the Create world -> Mods screen so you can manage, check, and fix your active mod list before generating a world.

========================================
FEATURES
========================================

- Mods Tab - Browse, search (f), load/unload (Enter or double-click, automatically placed by load-order rules), manually reorder (w / s), and batch Add all (Shift+A) or Remove all non-vanilla mods (Shift+X) alongside each mod's full description.
- Live Color Highlighting - Conflicting, missing-requirement, and duplicate-object mods light up in red, out-of-order mods in yellow, loaded custom mods in green, unloaded mods in cyan, and vanilla base-game modules in grey.
- Fix Load Order (f / a) - Automatically satisfies every mod's "must be before / after" rules while moving as few mods as possible and leaving vanilla mods in place.
- Batch Conflict Removal (c / a) - Reviews all declared conflicts in one checklist with suggested removals pre-ticked and removes them in a single confirmation.
- Missing Required Mods (l) - Flags missing dependencies and copies Steam Workshop search links to your clipboard for mods you do not have installed.
- Raw-File Scanner (r) - Scans active mod raws for hidden duplicate object definitions (DF errors) and suggests load-order fixes for mods that edit objects without declaring rules.
- Version Checker (v) - Spots active mods that have a newer installed version and switches to them in one step.
- Mod Info Inspector - Pick any active mod to see its author, full description, declared rules, other mods that depend on or conflict with it, and raw-file summary.
- Undo & Mod Manager Presets (u / p) - Undo up to 30 changes and save your fixed list directly to your DFHack Mod Manager preset.
- Create World Guard - Warns you if you click Create world while problems remain (click again within 30 seconds to proceed anyway).

========================================
QUICK KEYS
========================================

- d - Open the Mod Load Order details window
- a - Fix all (resolve conflicts, then fix load order)
- f - Filter mods (Mods tab) / Fix load order (Problems tab)
- w / s - Move selected loaded mod up / down (Mods tab)
- Shift+A / Shift+X - Add all / Remove all non-vanilla mods (Mods tab)
- c - Remove declared conflicts (Problems tab)
- v - Switch to newest installed versions (Versions tab)
- u - Undo last change
- p - Save as DFHack Mod Manager preset
- r - Rescan raw files

========================================
INSTALL
========================================

Subscribe on Steam Workshop with DFHack enabled. No activation in the Mods screen is required.
